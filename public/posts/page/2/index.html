Denon DJ MC4000 Software & Gear Specs Breakdown

Denon DJ MC4000 Specs & Compatibility

The Denon DJ MC4000 is a 2-channel DJ setup built for performance.

Hardware Overview

  • Brand: Denon DJ
  • Model: MC4000
  • Channels: 2
  • Jog Wheel Size: 133mm
  • Standalone Mode: False
  • XLR Outputs: True

  • Serato DJ: True
